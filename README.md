## ✨ Features

- 🔐 **User Authentication** – Registration, login, and logout functionality.
- 🏝️ **Destination Discovery** – Browse and explore different travel destinations.
- 🔎 **Sorting & Filtering** – Find destinations based on available sorting and filtering options.
- 🗺️ **Trip Planning** – Build and manage personalized travel itineraries.
- ❤️ **Wishlist** – Save favorite destinations for future reference.
- 🛒 **Shopping Cart** – Add and manage selected travel packages.
- 🎫 **Booking Management** – Manage bookings and view booking history.
- 💳 **Demo Checkout** – Interactive payment interface with form validation.
- 👤 **User Profile** – Access and manage profile information.
- 📱 **Responsive Design** – Optimized for desktop, tablet, and mobile devices.

## 🚀 Getting Started

Follow these steps to run TripNova locally.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Directory

```bash
cd TripNova
```

### 3. Open in Visual Studio Code

Open the project folder using Visual Studio Code.

### 4. Run the Website

Use the **Live Server** extension in VS Code and open `index.html` in your browser.

## 💻 Application Overview

TripNova provides a frontend-based travel exploration experience. Users can register, log in, discover destinations, manage wishlists, add travel selections to their cart, and complete a demo checkout.

The application uses browser LocalStorage to maintain user-related information, session data, and other application data.

**Note:** The payment functionality is for demonstration purposes only and does not process real financial transactions.
