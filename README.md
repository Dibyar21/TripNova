# ✈️ TripNova – Travel Explorer

**Explore More. Experience More. Travel Better.**

TripNova is a responsive and interactive travel exploration website designed to help users discover destinations, explore travel services, plan trips, and manage their bookings through a user-friendly interface.

The project focuses on providing a smooth travel-planning experience with modern UI design, interactive features, and demo booking and payment functionality.

## 🌐 Live Demo

- **Live Website:** [(https://tripnova.vercel.app/)]
- **GitHub Repository:** [(https://github.com/Dibyar21/TripNova)]

## ✨ Features

- **User Authentication:** User registration, login, and logout functionality.
- **Destination Exploration:** Browse and explore different travel destinations.
- **Destination Sorting:** Organize destinations using sorting and filtering options.
- **Trip Planning:** Build and manage personalized travel itineraries.
- **Wishlist:** Save favorite destinations for future reference.
- **Shopping Cart:** Add and manage selected travel packages.
- **Booking Management:** Manage bookings and view booking history.
- **Demo Payment:** Interactive checkout with payment form validation.
- **User Profile:** Access and manage user profile information.
- **Responsive Design:** User-friendly layout for desktop, tablet, and mobile devices.
- **Contact Section:** Provides a way for visitors to connect with the platform.

## 🚀 Getting Started

Follow these steps to run TripNova locally.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Folder

```bash

```

### 3. Open the Project

Open the project folder in Visual Studio Code.

### 4. Run the Website

Use the Live Server extension in VS Code and open `index.html` in your browser.

## 💻 Application Functionality

TripNova provides a frontend-based travel exploration experience. Users can create accounts, log in, explore destinations, manage wishlists, add selections to the cart, and complete a demo checkout process.

Browser LocalStorage is used for storing user-related information, session data, and other application data.

**Note:** The current payment functionality is for demonstration purposes only. It does not process real financial transactions.
