# TripNova – Travel Explorer 🌍

A responsive travel discovery website that helps users explore destinations, discover travel experiences, save favourite places, and create a simple travel itinerary.

### GitHub Repository: https://github.com/Dibyar21/TripNova
### Live Demo: tripnova.vercel.app

## 📌 Project Overview

**TripNova – Travel Explorer** is a front-end web development project developed as part of my internship at **Infrasoftech Pvt. Ltd.**

The project demonstrates the practical implementation of HTML5, CSS3, JavaScript, Bootstrap, jQuery, AJAX, and JSON to build an interactive and responsive travel website.

Users can browse destinations, search and filter results, view destination details, save favourites, and organize a basic itinerary.

## 🎯 Project Objectives

- Develop a responsive and user-friendly travel website.
- Apply front-end web development concepts in a practical project.
- Implement destination search, filtering, and sorting.
- Load destination data using AJAX and JSON.
- Store wishlist and itinerary selections using browser local storage.
- Practice website design, functionality, and testing.

## ✨ Features

- **Responsive Design:** Adapts the layout to different screen sizes.
- **Destination Discovery:** Displays travel destinations in an organized card layout.
- **Search Functionality:** Helps users find destinations using keywords.
- **Filtering and Sorting:** Makes browsing destinations easier.
- **Destination Details:** Displays additional information through a modal.
- **Wishlist:** Allows users to save favourite destinations.
- **Itinerary Builder:** Helps users collect destinations for a planned trip.
- **Demo Trip Request Form:** Demonstrates form handling and user feedback.
- **Newsletter Demo:** Provides a sample newsletter signup interaction.
- **Toast Notifications:** Displays feedback for user actions.
- **AJAX and JSON Integration:** Loads destination data asynchronously.
- **Local Storage:** Preserves selected information across browser refreshes.

## 🚀 How to Run the Project

### Option 1: Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Dibyar21/TripNova.git
   ```

2. Open the project folder:

   ```bash
   cd TripNova
   ```

3. Open the folder in Visual Studio Code.
4. Use the **Live Server** extension to run `index.html`.
5. Open the local URL provided by Live Server in your browser.

**Note:** Use a local development server so that the AJAX request for `data/trips.json` can work correctly.

### Option 2: View the deployed website

If GitHub Pages is enabled, visit:

`https://YOUR-USERNAME.github.io/TripNova/`

Replace `YOUR-USERNAME` with your GitHub username.

## 🔄 How It Works

1. The website loads its main HTML structure and styling.
2. JavaScript initializes the application's interactive features.
3. AJAX requests the destination data from the JSON file.
4. The application displays destination cards.
5. Users search, filter, sort, and view destination details.
6. Wishlist and itinerary selections are saved in browser local storage.
